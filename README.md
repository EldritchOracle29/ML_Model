# 🧠 CerebroCare

**CerebroCare** is an AI-powered, real-time health monitoring and early stroke detection platform. It integrates biosensors like EEG, ECG, SpO₂, and motion data to predict potential strokes and notify healthcare systems instantly.

🌐 **Live App**: [cerebrocare.streamlit.app](https://cerebrocare.streamlit.app)

## 🚀 Features

- Real-time health monitoring with multiple sensors
- Early stroke prediction using machine learning
- Emergency alert system for hospitals & caregivers
- Visual dashboards for live data tracking

## 🧰 Technologies Used

- Python, Streamlit
- scikit-learn, pandas, numpy
- Flask (for API)
- Embedded sensor integration (EEG, MAX30100, etc.)
